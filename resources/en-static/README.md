# Английская версия сайта (статичные страницы)

Отдельная английская копия публичных страниц nadezhda.space. Открывается по адресам:

| Страница | Адрес | Файл |
|---|---|---|
| Главная | /en | index.html |
| Вход | /en/login | login.html |
| Регистрация | /en/register | register.html |
| Сброс пароля | /en/forgot-password | forgot-password.html |
| Публичная оферта | /en/agreement | agreement.html |
| Политика конфиденциальности | /en/privacy | privacy.html |
| Пользовательское соглашение | /en/terms | terms.html |

## Как устроено

- Это обычный HTML. Правите текст прямо в файле — изменения видны сразу после выкладки, сборка не нужна.
- Стили и скрипты — свои копии в public/en-assets (app.css, app.js), чтобы страницы не ломались после пересборки русского сайта. Если на русском сайте поменяли дизайн и хотите то же на английском — скопируйте свежие public/build/assets/app-*.css и app-*.js в public/en-assets под теми же именами.
- Отдаёт страницы маршрут /en в routes/web.php. Он подставляет:
  - `__CSRF__` — токен защиты формы (без него вход и регистрация не работают, не удаляйте);
  - `__ALERT__` — короткое английское сообщение после ошибки формы или отправки письма.
- Формы входа, регистрации и сброса пароля отправляются в обычные обработчики сайта. После входа человек попадает в русский личный кабинет. Письма — русские.
- Кнопки «Buy in 3 clicks» и «Get started» ведут на русские страницы покупки и оплаты.
- Ссылка RU в меню главной ведёт на русскую главную.
